Formules utilisées

°Plato → densité : SG = 1 + P / (258,6 − (P/258,2)·227,1)
Densité → °Plato : P = −616,868 + 1111,14·SG − 630,272·SG² + 135,997·SG³
Brix ≈ Plato pour le moût.

Correction T° densimètre (polynôme de densité de l'eau, T en °F) : SGcorr = SGlue · f(Téch) / f(Tétal), f(T) = 1,00130346 − 1,34722124e-4·T + 2,04052596e-6·T² − 2,32820948e-9·T³

FG au réfractomètre (Terrill, « new cubic », bière fermentée) : FG = 1 − 0,0044993·OB + 0,011774·FB + 0,00027581·OB² − 0,0012717·FB² − 7,28e-6·OB³ + 6,3293e-5·FB³, OB et FB = Brix lus ÷ WCF. Peu fiable au-delà d'OG ≈ 1,080.

Alcool (Balling) : ER = 0,1808·OE + 0,8192·EA ; ABW = (OE − ER) / (2,0665 − 0,010665·OE) ; ABV = ABW · FG / 0,7907 (densité relative de l'éthanol à 20/20 °C).
Atténuation apparente = (OG − FG)/(OG − 1) ; réelle = 1 − ER/OE.

CO₂ résiduel : 3,0378 − 0,050062·T + 0,00026555·T² (T en °F, T max depuis la fin de fermentation).
Resucrage (stœchiométrie, 1 vol = 1,977 g CO₂/L) : sucre blanc 3,84 g/L/vol (saccharose → 4 CO₂) ; dextrose monohydraté 4,45 g/L/vol (→ 2 CO₂).
Alcool du resucrage (même stœchiométrie) : éthanol = sucre × 0,538 (sucre blanc) ou × 0,465 (dextrose) ; +% vol = g/L éthanol / 789,3 × 100. Dilution par le sirop (≈ 1 %) négligée.
